# 界面优化与验证入口

本文件补充 DEVELOPMENT_SPEC.md。现行文本和 Excel 样板遵循开发规范第 31 节，第一阶段的组件和试用记录见 [界面体系第一阶段](ui/PHASE1.md)。此前样板见 [UI-0.18.0.md](UI-0.18.0.md)。

## 先判断问题

- 布局：任务信息层级、区域比例、命令与目标的距离、窄窗遮挡。
- 视觉：字体、颜色语义、间距、图标、控件状态的一致性。
- 交互：发现入口、键盘路径、焦点、模式与反馈。
- 实现：原生窗口遮挡、异步结果、滚动同步、数据或渲染错误。

每次修改说明具体使用问题、修改位置和实际验证结果，不以截图美化替代流程修复。

## 文本样板规则

- 文件页签与窗口控制按钮共用顶部 38 DIP 全宽 WPF 标题栏（保留拖动区、非客户区按钮命中与系统贴靠，详见规范第 31.8 节）。文件超出一行时从计数入口查看或筛选。下方是独立的三段式审阅工具栏，左侧为显示范围和忽略空白，中间为差异步进器，右侧为查找、定位、刷新、主题和更多。
- 主比较区与单行状态栏整合于单张圆角底板内，左右窗格以 1 DIP 细线分隔。代码与 Excel 的正文右侧使用方案 A 的 16 DIP 单轨，直角浅带及上下发丝线标识可见范围，方形刻度保留差异语义。定位、拖动和悬停共用实际滚动坐标。
- 单行紧凑来源标题（34 DIP）：BASE 只读；右侧默认只读时仅显示“开启编辑”入口，开启编辑或存在未保存修改时按需展开撤销、重做与分裂保存。完整路径和传入标题可通过提示查看。
- 默认只读，开启编辑才允许更改。关闭保留未保存内容和历史；未知来源仍另存为。颜色和布局不得影响保存目标判定。
- 白色/深石墨单张正文底板与外框留出边距，控件和焦点采用黑白石墨配色。文本替换行的 BASE 侧为浅红底，当前侧为浅绿底，只有变化片段着色加粗，空位以低对比斜纹区分。差异正文与对应底色对比度至少 4.5∶1。
- 字体沿用系统 UI 字体与等宽代码字体，代码正文 15 DIP、行高 24 DIP。通用几何、主题和控件状态由 `Differ.UI` 管理，代码度量与差异语义由 App 管理。
- 普通、悬停、按下、选中、禁用、键盘焦点完整；焦点不改变布局尺寸。保存显示可操作状态，不用颜色暗示不存在的权限。
- 查找和定位按需占独立行，关闭恢复正文面积，禁止把 WPF 浮层直接盖在原生 WebView2 上。
- 查找每次定位真实命中的侧、行与字符范围，重复命中也应重新定位并保持输入焦点；长行横向可见。另存成功后右侧显示实际保存目标，完整提示区分原始比较来源与目标，并说明 F5 刷新读取来源。详见规范第 31.7 节。
- 长行保持左右同步水平滚动；长名称省略并保留工具提示；720 DIP 窄窗核心命令可用。

## Excel 样板规则

- 左右来源与修订在单行紧凑标题栏辨认，两侧原始坐标与选中单元格相互对应。
- 底部紧凑排布工作表标签、双侧地址与对照值、复制和展开。两侧值各自截断，始终保留方向箭头，未变化值使用正文色。展开后提供可字符级选中的完整双侧内容。工作表标签保留切换、计数与溢出滚动。

## 每次交付

1. 修改前读取开发规范并记录实际运行画面；参考用户认可的图，必要时核对同类产品官方界面。
2. 更新受影响规范后实施，常规视觉选择自主完成；只有影响整体方向或主要工作方式的取舍再确认。
3. 用相同输入、窗口尺寸、主题和位置记录前后截图。运行核心操作，测试长内容、窄窗及缩放，区分真实系统 DPI 与离屏模拟。
4. 截图/日志/临时运行副本放项目外；文档保留证据入口、操作结果、未验证项和试用入口。
5. 完成 Release build/test/format 及清理检查。第一阶段交付项目外隔离预览。正式版本走固定目录发布流程。未完成的验证如实列出。

参考：用户 2026-11-09 认可的简约液态玻璃单张圆角底板（V3）效果图；[VS Code 双栏审阅](https://code.visualstudio.com/docs/sourcecontrol/overview)与 [WinMerge 文件比较](https://manual.winmerge.org/en/Compare_files.html)用于核对阅读、导航和编辑操作分组，不引入其提交/合并流程或品牌资产。

所有文本差异组的普通/选中左侧提示条均使用连续圆角端头：5 DIP宽、2.5 DIP半径，真实端头内收1 DIP；视口裁切处保持平头，不改变正文行高。选中正文轮廓4 DIP圆角。验收必须覆盖未选中和选中两种状态，并核对用户实际启动入口的版本，不能只核对开发目录。最新纠正记录见 [UI-0.18.2.md](UI-0.18.2.md)。
