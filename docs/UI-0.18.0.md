## 当前问题与改造

1. 布局：保存/撤销在全局栏左侧，编辑开关在右侧，操作与目标距离远。编辑组集中在右侧标题，阅读范围留左、差异导航居中。
2. 实现：实际按 Ctrl+F 后查找面板被原生 WebView2 正文遮挡。查找/定位改为按需出现的独立布局行。
3. 视觉与交互：普通工具、模式状态、主要动作层级弱，WPF 和 Monaco 状态色不一致。文本样板采用浅紫灰操作区、紫色选中/保存、明确编辑开关；正文 15 DIP 配合 24 DIP 行高，统一行号、选择、滚动条和焦点色。

用户图片为首要视觉参考；[VS Code](https://code.visualstudio.com/docs/sourcecontrol/overview) 和 [WinMerge](https://manual.winmerge.org/en/Compare_files.html) 用于核对双栏阅读与导航分组。保持工具栏在文件标签上方、原生窗口框架和左侧概览，延续现有使用方式。
