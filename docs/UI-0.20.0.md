## 最终交互

- 来源/结果分界处是一条固定冲突操作行：上一处、明确的当前编号/状态、下一处、采用我的/基础/对方、确认已解决。按钮位置不随计数变化；顶部移除重复导航，仅留查看工具。
- 待解决总数靠近结果标题；撤销/重做、保存、保存并完成继续靠结果区域。
- “自动下一处”默认关闭，仅本会话生效。开启后首次解决当前冲突会跳到下一待解决项，跳过已解决项；最后一处停留，不自动保存。改选、撤销、重做不触发自动下一处。
- 撤销/重做定位其实际改变的冲突，方便检查或重新取舍。重复双击和按键重复不能把决定施加到尚未阅读的下一块。
- 点击结果中的冲突会按当前版本字符范围选择对应操作目标，并同步来源；不改变结果光标、选区或滚动。拖动选择文字、双击选词和普通上下文点击保留清晰标注的原当前目标。未同步输入先完成同步再解释位置，空增删锚点和跨块手工编辑仍遵守范围保护。
- 保留默认隐藏基础及本地记忆、双主题、查找、阅读缩放和所有安全保存规则；不改变三方算法或真实SVN绑定。
