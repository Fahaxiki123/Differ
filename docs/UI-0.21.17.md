## 完成的交互

- 查找现在传递真实命中的侧、原始行号、UTF-16 列及长度，字符范围单独描边。仅 BASE 命中时不会误定位右侧。滚离后再次 Enter，即使仍是同一行、同一匹配，也重新定位。
- 长行查找同时调整水平位置；两侧共享可滚范围，解决对侧尚未测量长行或整侧只有短行时被钳回左端的问题。共享宽度通过零高度视图区实现，不改正文、不补空格、不重建文档。宽窄往返、阅读缩放及新会话清理单独回归。
- 查找输入焦点、Monaco 原有选区和撤销历史保留。清空查询、关闭面板、内容更新或换会话会清除失效高亮；迟到的展开/定位请求受会话、文档版本和导航序号保护。
- 保留旧样板的计数规则：每个命中逻辑行计一条，每行优先定位右侧首个出现位置，右侧没有才定位 BASE；本轮没有改成逐个遍历同一行的所有出现位置。
- 另存成功后，右侧紧凑标题显示实际目标文件名，完整提示区分原始比较来源、保存目标，并说明 F5 仍读取原始来源。再次保存使用已确认目标；失败或取消另存不提前换提示。
- F5 成功刷新后，目标显示和保存状态随新会话恢复。保存权限、外部修改指纹校验、BASE/快照保护、编码/换行和原子写入规则保持原状。
- 720 DIP 窄窗且已有另存目标时，“结果副本”简写为“结果”，编辑开关隐藏装饰图标以保留目标名称空间；状态和全部命令仍可见，标题行仍为 34 DIP。
