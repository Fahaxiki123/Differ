# 0.19.1 合并基础窗格显示选项

用户希望通常只比较双方文件，自行决定是否查看共同基础。本轮是合并页面的布局/交互调整，基础仍参与三方判断。

- 默认隐藏共同基础，上部“我的 / 对方”各占一半；下部完整合并结果保留。
- 工具栏增加“显示基础”选中按钮，打开后恢复三等分来源窗格。选择保存在本地偏好，旧设置默认隐藏。
- 显示切换不重建Monaco模型，不改变文本、解决状态、当前冲突、撤销/重做或保存目标。“采用基础”仍可使用。
- 窄窗来源标签同步显隐；正在查看基础时关闭开关则切到我的。查找不聚焦隐藏来源，隐藏编辑器不抢占同步滚动。
