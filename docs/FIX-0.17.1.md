# Differ 0.17.1：编辑闪烁修复

2026-10-26。依据用户录屏 `Recording-20261026-221545.mp4`：上下文模式、空 BASE 对 8 万行新增 C# 文件，输入时正文在白底/语法色与绿色差异底色/粗体之间反复切换。

## 根因与修改

旧流程每次输入都清空双侧差异高亮，100 ms 合批及重算后补回行底色，再等字符细化往返补回文字样式。更新投影时还会删除重建对齐空白区；左侧概览绑定的行集合也同步清空。这些中间帧在仅比较更新前后两个画面的测试中不可见。

- 连续输入保留未受影响的 Monaco 跟踪标记，当前结果仍立即失效；过期块不可采纳或导航。
- 纯增删文字与行底色同时绘制，不再依赖延迟的字符请求逐层变色；普通修改只移除已失效的字符片段，按当前版本更新。
- 行标记原子替换，对齐空区复用 DOM 和 view zone，通过公开布局 API 原位更新高度/锚点；不再每次恢复整个视图或重复全部折叠。
- 概览保留只用于绘制的最后有效快照，更新期间关闭旧点击/悬浮预览。比较失败、刷新与会话切换清理相应缓存，旧结果不能当作当前结果使用。
- 比较选项变动时取消上一轮字符细化并清空旧块选择，避免同一文本版本下迟到的旧选项结果混入新显示。
- 完整文档、光标、选区、撤销历史、编辑开关及保存保护保持原实现边界。
