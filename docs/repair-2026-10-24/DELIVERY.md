## 源码变更

1. **Excel**：新建逻辑列/行映射，比较节点和网格消费同一份对应关系；支持多行表头、数据起始、组合键、重复字段歧义及人工映射。唯一键不再因少量异常整表失效；新增/删除/重排为独立结构事件；内容、格式和引用调整区分。映射保留双侧真实坐标，表头和业务列可冻结。主要源码为 `LogicalColumnMapper`、`LogicalRowMapper`、`LogicalSpreadsheetComparer`、`MappedFormulaComparer`、`SpreadsheetRulesWindow`。详见 [Excel 报告](excel.md)。
2. **Word**：Word 专用有预算的中文局部匹配，稳定边界、拆合段和连续改写组；长组共同折叠并保留全部搜索/复制内容，搜索目标进入可见窗口首段；首行/悬挂/列表标记独立布局。普通段落使用轻量控件，仅确需特殊缩进或主动字符选择时创建富文本控件。主要源码为 `WordUnitAligner`、`WordChangeGroupViewModel`、`WordParagraphHost`、`WordParagraphPresenter`。详见 [Word 报告](word.md)。
3. **文本编辑**：完整双侧 Monaco 文档，右侧编辑、块采纳、撤销重做、语法及搜索。验证 Monaco Diff Editor 后发现公开 API 不能保留原忽略选项，因此最终选用 **双 standalone Monaco + 宿主有界 DiffPlex 唯一权威结果**。没有双重全文比较或双编辑器路线。版本/会话失效保护覆盖投影、导航、计数、搜索、导出及块坐标；原位更新保留光标、选区、滚动和撤销链。主要源码为 `EditableTextSession`、`EditorDiffEngine`、`CodeEditorView` 与 `Editor/editor.js`。详见 [编辑器报告](editor.md)。
4. **保存**：BASE/快照不可写；未知和历史来源默认另存。新协议 `--source tortoisesvn` + `WC` 修订 + SharpSvn 公开本地 API + 快照哈希全部通过才确认真实工作文件；失败安全降级。保存校验外部变更，最后校验持有拒写句柄，再同目录完整写入并替换。编码/BOM/换行保真，混合换行编辑时明确选择，不可编码字符拒绝保存。关闭/刷新/退出处理未保存内容。
5. **性能及界面**：后台全工作簿搜索和旧查询取消；保留两 worker、虚拟化与预算；减少 Excel 重复签名/元数据和重复选中布局，Word 字符差异按需生成；长行受限细化保留共同中段。统一区域/结构/单元格/格式单位、当前块及保存状态。新增内容无关的阶段测量，日志不包含正文。

规范已同步至 `docs/DEVELOPMENT_SPEC.md` **4.0.0**（第27节及变更记录）。旧测试中与新任务冲突的“异常键整表回退、插行附尾、重排无结构事件”等断言已按新语义调整；CSV兼容行为保留。未执行 SVN update/revert/add/delete/commit，未自动改写当前用户的 SVN 绑定。

## 性能前后对照

方法、环境、样本及限制见 [PERFORMANCE.md](PERFORMANCE.md)，完整前后中位数/范围、p50/p95/max见 [PERFORMANCE_RESULTS.md](PERFORMANCE_RESULTS.md)。原始JSON保留所有事件及输入哈希。

- Excel 10k×40：适配器暖中位数约 **3076.5→2453.0ms**，托管分配 **1729.9→1452.5 MiB**；分配是累计分配量，不是常驻内存。
- 插列样本：**173.3→125.9ms**，误报从 **24025→2**，真实语义为一列新增+一格修改。
- Excel可见格选择 p95 **18.47→4.02ms**；切Sheet **8.58→5.56ms**；已加载文件切换 **7.94→5.14ms**。
- Word普通滚动 p95 **8.29→8.49ms**，远跳 **33.48→34.20ms**，区域导航 **33.22→33.38ms**。开发中发现并修掉的富文本控件回退数据仍在provisional中保留，不冒充最终结果。
- Excel远跳 p95约 **120ms**，远距离格导航约 **167ms**，仍超过100ms；普通滚动p95约53ms，不能声称达到60Hz。
- 新文本会话有保存指纹/版本和有界匹配成本，部分纯算法样本较旧只读路径稍慢；没有声称全面提速。10k行输入帧反馈 p95约2ms；含100ms合批的权威结果渲染p95约204ms。
